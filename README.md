# Monster Hunter Wilds Artian Reroll Helper

A utility for planning Artian weapon rerolls in Monster Hunter Wilds.

This tool helps estimate and reduce the materials needed when rerolling Gogmazios Tarred Devices, based on the reroll patterns I observed while playing.
